# What is this?

In folderul acesta exista doua fisiere, [strat1.py](./strat1.py) si [strat2.py](./strat2.py), care reprezinta cele doua strategii teoretizate in [README-ul](../README.md) din root-ul repo-ului.

Fiecare fisier arata cum ar trebui sa functioneze fiecare strategie intr-un context ideal, unde nu exista API-uri cu sisteme de control al accesului si al numarului de cereri de procesat.

Setul de date este unul generat, iar paginile web sunt simple pentru a arata modul de functionare efectiv.
